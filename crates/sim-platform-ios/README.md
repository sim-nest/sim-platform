# sim-platform-ios

The iOS AOT capsule statically exports the existing `sim_native_abi_v1` byte
function table. A thin Swift scene shell owns UIKit lifecycle, security-scoped
URLs, permission callbacks, notification and audio-session glue, background
limits, and memory pressure. Rust retains only typed lifecycle and service
state; suspension drops resources and document grants and makes unavailable
services refuse deterministically.

Local evidence proves the modeled/static ABI corpus, exact Rust target specs,
and host archive imports. The committed evidence does not claim App Store,
physical-device, Xcode SDK linkage, or simulator execution; those require the
authorized hosted closeout job.
