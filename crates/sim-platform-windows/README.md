# sim-platform-windows

This additive capsule realizes frozen platform and domain ports through private
Win32/WinRT choices. Consumers see only Card service identities and the existing
`sim_native_abi_v1`; executable suffixes, drive letters, separators, handles,
package identity, and permission declarations remain here.

The checked artifact evidence is cross-built and import-inspected. It is not a
claim of hosted or physical Windows execution.
